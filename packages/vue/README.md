# @ikions/vue

Vue 3 components for Ikions icons, with Outline and Filled variants.

## Install

```bash
npm install @ikions/vue
```

## Usage

```vue
<script setup>
import { CameraIcon } from "@ikions/vue";
</script>

<template>
  <CameraIcon :size="28" variant="filled" />
</template>
```

Props: `size`, `variant`, `color`, `stroke-width`, `title`. Requires Vue 3.3+.

See the documentation on the Ikions website (/docs).
