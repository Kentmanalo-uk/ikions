# @ikions/svelte

Svelte 5 components for Ikions icons, with Outline and Filled variants.

## Install

```bash
npm install @ikions/svelte
```

## Usage

```svelte
<script>
  import { CameraIcon } from "@ikions/svelte";
</script>

<CameraIcon size={28} variant="filled" />
```

Props: `size`, `variant`, `color`, `strokeWidth`, `title`, `class`, plus any SVG attribute. Requires Svelte 5.

See the documentation on the Ikions website (/docs).
